# Backend — Teams Actas Agent

Esta carpeta contiene el servidor Express/tRPC: `server/`, los tipos compartidos en `shared/` y el esquema en `drizzle/`.

La API usa las variables del archivo `.env` ubicado en la carpeta raíz, especialmente `GROQ_API_KEY`, Microsoft 365 y SharePoint.

El comando recomendado se ejecuta desde la raíz:

```cmd
cd /d C:\TeamsActasAgent\teams-actas-agent
pnpm dev
```
