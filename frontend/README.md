# Frontend — Teams Actas Agent

Esta carpeta contiene la interfaz React/Vite: `client/`.

El proyecto completo se ejecuta desde la carpeta raíz para que frontend y backend compartan tRPC, configuración y variables de entorno:

```cmd
cd /d C:\TeamsActasAgent\teams-actas-agent
pnpm install
pnpm dev
```

No pongas claves API dentro de esta carpeta ni en archivos del navegador.
